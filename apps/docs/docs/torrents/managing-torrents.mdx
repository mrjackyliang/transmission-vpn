Find torrents with filters and search, act on several at once, and adjust each one from its details panel.

## Find Torrents

- **Torrent library** — On wide screens, the sidebar lists **Status**, **Profiles**, and **Labels**, in that order. Every row has a torrent count, and selecting the active row again clears it.
- **Profile filters** — Choose a <Terminology title="The folder, VPN connection, labels, and defaults that belong to a torrent" to="/docs/reference/terminology#profile">profile</Terminology> to show its torrents. The profile with the Default role is first, followed by named profiles alphabetically.
- **VPN filters** — Select a connection's torrent count on **VPN** to open the library with that connection applied. The active pill reads **VPN: &lt;name&gt;**.
- **Status filters** — **All torrents**, **Active** (transferring now), **Downloading**, **Seeding**, and **Paused** always show. **Needs a profile**, **Checking**, **Warnings** (a tracker that warned or isn't working), and **Errors** (a local problem such as missing data or a full disk) appear when a torrent needs them.
- **Tracker notes** — A torrent whose tracker isn't working keeps its state and shows **Tracker not working** or **Tracker warning** beside it. Public torrents keep finding peers through DHT and peer exchange, while private torrents depend on their trackers. Hover the note, or open the **Trackers** tab, to read the tracker's reply.
- **Search** — The search box matches torrent names, folder paths, and labels.
- **Active filters** — The filters in use appear as removable pills under **Search** at every width, with **Clear all** whenever a filter is active.
- **Sorting** — Select a column heading (**Name**, **Progress**, **Size**, **Down**, **Up**, **ETA**, or **Ratio**) to sort, and select it again to reverse the order. **Size**, **ETA**, and **Ratio** show only on wide screens.
- **Queue column** — **#** appears when every torrent in the list is on one VPN connection, such as when only one connection exists, a **VPN: &lt;name&gt;** filter is on, or a profile filter's torrents share a connection. Select it to sort by queue position.
- **Pages** — The menu under the list shows 25, 50, or 100 rows per page.
- **Sidebar overflow** — When more Status, Profiles, or Labels rows continue below the sidebar, its bottom edge fades. The fade clears when the last row is visible.

Each torrent row carries a VPN tag with the name of its connection. This shows which tunnel carries that torrent's traffic, while a **Needs a profile** tag identifies an unresolved remote add.

The list refreshes every 2 seconds while the page is open. While it's closed, [Notifications](/docs/alerts/notifications/) can tell you when a torrent finishes, reports an error, or needs a profile choice after a remote add.

If a connection's Transmission is too busy to answer a refresh, for example while it deletes a removed torrent's files, the list keeps showing that connection's torrents as they last loaded, for up to 30 seconds.

## Navigate Between Pages

Each console page has its own address, so browser Back and Forward, refresh, and bookmarks return to the same page. When an address asks you to sign in, a successful sign-in opens that requested page.

- `/` or `/torrents` — **Torrents**.
- `/vpn` — The VPN connection list; `/vpn/new` opens **New connection**, and `/vpn/<connection-id>` opens a saved connection.
- `/remote-apps` — **Remote apps**.
- `/settings` — **Settings**.
- `/notifications` — **Notifications**.
- `/account` — **Sign-in and security**.

## Navigate on a Phone

Below 1020 pixels wide, the bottom bar shows at most four tabs in this order: **Torrents**, **VPN**, **Apps**, and **More**. **Apps** opens **Remote apps**.

On the **Torrents** page, **Filters** beside **Search** opens a sheet with **Status**, **Profiles**, and **Labels** and their counts, **New profile**, every profile's **⋯** menu, and **Edit** beside **Labels**. Selecting a row applies the filter and closes the sheet, and the number on **Filters** counts the active filters. Tapping the tab of the page you're on scrolls it back to the top.

**More** opens a sheet with **Settings**, described as `Queue, network and blocklists`, and **Notifications**, described as `Where alerts are sent`.

The account menu contains **Appearance**, **Sign-in and security**, and **Sign out** at every width.

## Batch Actions

1. Select the check box on each torrent, or Shift-click a second check box to select the range between them on the current page.
2. Use the bar that appears at the bottom of the page, which counts the selected torrents.

<Frame caption="The Change profile selection bar below a profile-choice banner">
  <ThemedImage sources={{ light: managingTorrentsTwoLight, dark: managingTorrentsTwoDark }} alt="Torrents searched for linux with a profile-choice banner, two torrents checked, no queue number column across several connections, and a 2 selected bar with Start, Pause, Change profile, Remove, more actions, and clear buttons" width={1024} height={900} style={{ maxWidth: '100%', height: 'auto' }} />
</Frame>

| Control             | What it does                                                                           |
|---------------------|----------------------------------------------------------------------------------------|
| **Start**           | Starts the selected torrents, following the download queue.                            |
| **Pause**           | Stops transfers for the selected torrents.                                             |
| **Change profile**  | Moves each torrent's files and, when needed, moves it to the profile's VPN connection. |
| **Remove**          | Removes the torrents, and optionally their data.                                       |
| **More actions**    | Opens the action menu for the selected torrents.                                       |
| **Clear selection** | Unselects every torrent.                                                               |

**Change profile** also offers **Also apply its labels and limits**. Leave it off to keep the selected torrents' labels and per-torrent options.

- The check box in the column heading selects every torrent on the current page.
- The selection only covers torrents on screen. Switching to another list under **Status**, **Profiles**, **Labels**, or a VPN connection clears it, and a search, another page, or a torrent leaving the list unchecks the torrents it hides.
- One action can include up to 1,000 torrents.

### Action Menu

Right-click a torrent, or select the actions button at the end of its row, to open the action menu. When the torrent is part of the selection, the menu acts on every selected torrent.

- **Start** and **Start now, skip the queue** — The second starts the torrents right away, ahead of the queue.
- **Pause** — Stops their transfers.
- **Verify local data** — Checks the downloaded data against the torrent.
- **Ask trackers for more peers** — Announces to the trackers again.
- **Download torrent file** — Saves the torrent's `.torrent` file. With several torrents selected, **Download torrent files** saves them as one zip. A magnet still fetching its metadata has no file yet, so it's left out, and the option is unavailable when none of the torrents has one.
- **Download finished files** — Downloads a finished torrent's file to the computer you're using, or its files as one zip with the torrent's folder inside. With several torrents selected, all of their files come as one zip. The option appears once one of the torrents has finished downloading, and a torrent that hasn't finished, or whose files were moved or deleted, is left out. The browser shows the progress, and a single file picks up where it stopped if the connection drops. It needs a signed-in browser, so API tokens can't use it.
- **Move to top of queue**, **Move up one**, **Move down one**, and **Move to bottom of queue** — Change their place in the queue.
- **Remove…** — Opens the same confirmation as **Remove**.

## Resolve Needs a Profile

When a remote app adds a torrent whose name matches several profiles and no folder or label chooses one, the torrent is added paused with the Default profile's folder and connection. Its row gets a **Needs a profile** tag, and **Needs a profile** appears under **Status**.

The banner says `1 torrent matches more than one profile.` or `<N> torrents match more than one profile.` Select **Resolve** there, or open the torrent details and select **Resolve**.

  <ThemedImage sources={{ light: managingTorrentsTenLight, dark: managingTorrentsTenDark }} alt="Top of the Torrents page with a 1 torrent matches more than one profile banner and its Resolve button, a Needs a profile row under Status, and Example.Show.S01E04.2160p paused with a Needs a profile tag" width={1280} height={900} style={{ maxWidth: '100%', height: 'auto' }} />

**Choose a profile** lists each matching profile with the pattern that matched. Choosing one moves the torrent to that profile's folder and VPN connection, adds its labels to the ones the remote app set, applies its limits, and starts it unless the profile has **Start paused** selected.

If the original matching profiles are unavailable, the dialog explains that and offers every profile.

## Torrent Details

Select a torrent to open its details panel, which shows its status, queue position, progress, speeds, and time remaining, with **Pause** (or **Start** when the torrent is stopped), **Verify**, and **Reannounce** buttons. A torrent marked **Needs a profile** also has **Resolve**.

The **Pieces** map at the top of **Overview** shows which parts of the torrent are on disk:

- **Squares** — Each square is a run of pieces, and it gets greener the more of them are here. **1 square =** says how many pieces each square holds, since big torrents group more pieces per square.
- **Amber outline** — No connected peer has a missing piece in that square, so the torrent can't finish until such a peer connects.
- **Hover** — Hovering a square shows its piece numbers, how many are here, and how many peers have the rest.

| Tab          | Contents                                                                                                                                                                                                             |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Overview** | A **Pieces** map, then ratio, peers, data downloaded and uploaded, dates, VPN connection, time spent downloading and seeding, location, info hash, the magnet link with a copy button, the creator, and the comment. |
| **Files**    | Which files to download and their priorities (High, Normal, or Low), with a filter, **All**, **None**, and **Priority for all…**, saved with **Save**.                                                               |
| **Peers**    | Connected peers with their address, client, progress, and speeds.                                                                                                                                                    |
| **Trackers** | Each tracker's tier, last announce result, and counts, plus **Tracker list** for editing the trackers, saved with **Save**.                                                                                          |
| **Options**  | Profile, labels, bandwidth priority, maximum peers, speed limits, ratio and idle rules, and the **Name** section with its **Rename** button.                                                                         |

- **VPN connection** and **Location** are read-only on **Overview** because the torrent's profile owns both.
- **Profile** assigns a profile or the **Default profile**. Before **Apply**, the hint says where the files move and, when the VPN differs, which connection's Transmission receives the torrent.
- **Also apply its labels and limits** copies that profile's labels, seeding rule, speed limits, priority, peer limit, and queue position when you select **Apply**. It stays optional.
- **Seeding** offers **Custom** and **Never stop** for the ratio and idle rules. A note identifies the assigned profile as the source of the defaults.
- **Name** renames the top-level file or folder without moving it. A magnet must finish receiving its metadata before **Rename** is available.
- **Tracker list** takes one tracker per line, with a blank line between tiers, up to 256 KiB in total.
- **Follow global speed limits** decides whether the session-wide speed limits also apply to the torrent.

## Session Statistics

- **Header** — The top of the **Torrents** page counts the torrents, the ones downloading, and the ones seeding, and shows the current download and upload speeds.
- **This session** — Below the list, the data downloaded and uploaded since Transmission started.
- **All time** — Below the list, the data downloaded and uploaded across all sessions.

## Removing Torrents and Data

1. Select the torrents, then select **Remove**, or **Remove…** in the action menu.
2. Turn on **Also delete the downloaded files** only if you want the files deleted too.
3. Select **Remove**, which reads **Remove and delete files** when the files go too.

Without that option, the torrents leave the list and their files stay on disk.

:::danger
**Also delete the downloaded files** deletes the files from `/data`, and the web interface can't bring them back.
:::
